# Contributing

Use Node.js 24+, pnpm 10.34.5, and the committed lockfile. Activate that exact version with `corepack prepare pnpm@10.34.5 --activate` before installing.

1. Create a focused branch and keep unrelated changes out.
2. Do not include real customer media, secrets, private registry rows, private exact maps, local databases, absolute user paths, or generated caches.
3. Preserve fail-closed ownership boundaries. A locator, partial result, timing map, DNA, or transport receipt cannot become ownership authority.
4. Run `pnpm run typecheck`, `pnpm run build`, `pnpm run test:public`, and `pnpm run test:toolchain-supply-chain`.
5. Update robustness documentation only from frozen, inspectable evidence.
6. Add `I agree to the TancMark CLA v1.0` to the pull request.

A pull request may be merged only with explicit approval from the project owner or a maintainer explicitly designated by the project owner.

External-provider tests must remain skipped unless the contributor supplies their own isolated account and credentials. Never commit those credentials.
