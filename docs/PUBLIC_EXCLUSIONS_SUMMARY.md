# Public Exclusions Summary

The public archive is generated from a clean, independent one-commit repository. Private exclusions are tracked in a separate owner-only ledger that is not published.

Excluded categories include secret/key records, personal or customer records, private media and fingerprints, DNA/Chief Brain learning records, internal operational evidence, private legal/commercial material, and historical superseded records. Exact private paths, names, hashes, fingerprints, and contents are intentionally absent from this summary.
